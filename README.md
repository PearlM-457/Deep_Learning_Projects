## Running a project locally

```bash
git clone https://github.com/PearlM-457/Deep_Learning_Projects.git
cd Deep_Learning_Projects/<project-folder>
```

Each folder has its own README with setup steps. Browser-based projects (`translator`, `movie_night_site`) need no install. Serve the folder with `python -m http.server` and open it in your browser.
